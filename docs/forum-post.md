# 论坛发布稿：写给 PICKCAT 的一封「复活信」

> 用途：发在 PICKCAT 论坛（话题）或编程猫社区的帖文草稿。
> 建议标签：创作与作品 / 闲聊灌水（按论坛当前板块选一个）
> 标题候选见文末。

---

## 正文

**先说结论：那个 2021 年在「新社区初代体验团」里被反复截图、被讨论了二十期的 Pickcat，它的移动端，现在又能跑了。**

不是怀旧截图，不是概念稿，是能点开、能登录、能刷推荐、能进喵圈、能看作品、能收消息的一个网页版。

### 一、我翻了一遍当年那些帖子

2021 年 4 月，有一位叫「旁观者JErS」的体验团成员开始连载《入新社区初代体验团的所见所闻》，一直写到第二十期。那时候的帖子内容现在看很有意思：

- 群里 400 多号人，进群要改「昵称＋ID」；
- 每一期都是投票、意见汇总、公告截图；
- 有人认真讨论「新社区到底该像 B 站还是像论坛」；
- 第十九期干脆写成了一份 Pickcat 使用教程：怎么下载、怎么切换登录环境、主页在哪、怎么发作品、发动态只能放 1 张图、作品介绍限 500 字……

那批帖子记录的，其实不只是一个 App 的功能，而是一群人看着它从内测里长出来的过程。

后来 Pickcat 停了。原始安装包被加固，服务端环境变了，分发渠道断了。留下的只有背景图、底部导航那排小图标、登录页素材，和这些还在的帖子。

### 二、所以我把数据接回去了

这次没有魔改旧安装包。做法是把 Pickcat-Reborn 那套界面留下来，**把数据层整个换成现在 PICKCAT 官方的接口**（`pickcat.dao3.fun/api/v1`），一共 119 条路由，一条条对着接。

现在的样子：

- **首页**：推荐 / 发现 / 关注，三个流都是真的内容；
- **喵圈**：官方板块（兴趣广场、创作与作品、活动与赛事……）直接变入口，点进去就是话题流；
- **帖子**：正文、楼层、楼中楼、表情，全部按原样渲染；
- **作品页**：封面、Play 角标、浏览量 / 点赞 / 收藏 / 评论、作者主页跳转、评论列表；
- **播放**：Kitten4 / Kitten3 / KittenN / Nemo / CoCo / 海龟 六种引擎按官方地址规则走；**MOSS 也接了**——播放器反代 + 一次 OIDC 单点登录，用 PICKCAT 账号换 MOSS 会话；
- **消息**：全部 / 回复 / 赞 / @我 / 系统 五栏，未读红点、一键已读、点进去直达对应楼层；
- **登录**：不用再去开发者工具里复制 Cookie 了。账号密码 + 阿里云滑块，就在页面里登；
- **形态**：手机端优先，桌面也能用；没有后端数据库，登录态存在你自己的浏览器里。

### 三、为什么值得做这件事

我在整理资料的时候看到一句话，记到现在：

> 有些产品死掉，不是因为它从未存在，而是因为它存在过，却没有被好好记录。

Pickcat 就是这样。它留下的证据其实不少：启动页的颜色、登录页的星球、底部那四只小图标、还有上面那一堆帖子。问题是这些证据在慢慢散——链接失效、图床挂掉、截图损坏。

所以我做的这件事，一半是「让它重新能用」，另一半是「在证据彻底散掉之前，把能确认的东西固定下来」。

### 四、现在能做什么，还需要什么

现在的版本已经能日常逛：看推荐、翻论坛、看作品、收消息、发帖回复（登录后）。

还缺的、想请大家帮忙的：

1. **真实使用反馈**：哪些页面在你的手机上错位、哪些操作会卡、哪些文案不对；
2. **历史素材**：如果你手里还有当年的 Pickcat 截图、录屏、安装包、群公告，欢迎丢过来——尤其是「十九」和「二十」那两期里贴过、但现在可能已经打不开的图；
3. **功能建议**：搜索、收藏夹、通知聚合、深色模式，哪个对你更重要，我先做哪个。

项目是开源的，代码在这里：
`https://github.com/CodeManTeam/pickcat-web`

### 五、几句必要的说明

- 这是**第三方独立客户端**，和 PICKCAT 官方没有关系，没有使用任何官方私有代码，只调用公开接口；
- 界面沿用 Pickcat-Reborn 的开源实现，素材版权归原作者；
- 仅供学习交流，不做商用；
- 账号密码只在你自己的浏览器里走，服务端不落盘、不保存会话。

### 写在最后

2021 年那群人在群里投票、写公告、截图发帖的时候，大概不会想到五年后有人拿着这些帖子，把一个移动端重新拼出来。

但这件事成立的原因很简单：**只要证据还在，体验就还能被拼回来。**

如果你也记得那个蓝色启动页，欢迎来试试，然后告诉我哪里还不对。
